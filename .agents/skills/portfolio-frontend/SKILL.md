# Portfolio frontend

- Use the approved plan and content inventory to choose a focal point for each page. Structure project content around engineering decisions and evidence.
- Give light and dark themes shared semantic design tokens. Honor system preference on the first visit and keep manual preference across reloads. Verify that the initial theme is applied before paint.
- For the IoT visualization, make device-to-application flow understandable in a static state. Use keyboard and touch operable controls for node details. Provide equivalent text and respect reduced motion.
- Render the primary content statically. Keep the interactive code scoped to controls that need it. Use approved project images or clearly indicative conceptual visuals.
